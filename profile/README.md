Paxeer is a network for machine commerce. Agents do the work, this chain is where it settles.

LayerX is the lane we built for that — the high-frequency stuff that doesn't belong on a general-purpose block. We're redesigning that layer right now, so this org is going to look a little messy for a while. That's expected.

[Sidiora Labs](https://github.com/Sidiora-Labs) builds the agents and a lot of the protocol work. This org is the network side: the chain, the explorer, wallets, markets, and whatever else has to live next to them.

If you're looking for a place to start, [paxeer.app](https://paxeer.app) is the front door. LayerX has its own site at [layerx.paxeer.app](https://layerx.paxeer.app) — limited beta opens September 7.

A few other companies use these names. If it doesn't come back to paxeer.app, layerx.paxeer.app, or Sidiora Labs, it's not us.
